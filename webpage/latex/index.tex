Welcome to the documentation for the {\bfseries{Dual-\/\+Projector Projection System}}.

This project coordinates two projectors to display a combined image across a screen. The projected regions overlap, and a blending mask adjusts brightness in that overlap to make the combined image appear more continuous.\hypertarget{index_autotoc_md0}{}\doxysection{\texorpdfstring{System overview}{System overview}}\label{index_autotoc_md0}
The system uses the projector configuration, screen geometry, and selected projector side to determine which part of the combined image each projector displays. A blending mask controls the brightness of pixels in the overlap region.

Key terms:


\begin{DoxyItemize}
\item {\bfseries{Projection width ({\ttfamily w})}}: width, in centimetres, covered by one projector on the screen.
\item {\bfseries{Projector spacing ({\ttfamily d})}}: distance, in centimetres, between the two projectors.
\item {\bfseries{Overlap}}: screen region illuminated by both projectors.
\item {\bfseries{{\ttfamily overlap\+Px}}}: overlap width expressed as a whole number of pixels.
\item {\bfseries{Region}}: the horizontal part of the combined image assigned to one projector.
\item {\bfseries{Mask}}: a list of brightness multipliers from {\ttfamily 0} (black) to {\ttfamily 1} (full brightness).
\item {\bfseries{Gamma ({\ttfamily gamma})}}: parameter that shapes the brightness fade across the overlap.

\begin{DoxyItemize}
\item {\bfseries{{\ttfamily Pipeline\+Class}}} coordinates the image-\/processing pipeline.
\item {\bfseries{{\ttfamily Setup\+Class}}} loads and validates settings such as projector resolution, image width, projector spacing, blending gamma, source path, and projector side.
\item {\bfseries{{\ttfamily Math\+Class}}} calculates overlap width, total projection width, pixel density, overlap pixels, image regions, and blending masks.
\item {\bfseries{{\ttfamily Region}}} represents a horizontal region using its starting pixel and width.
\item {\bfseries{{\ttfamily Mask}}} stores per-\/column brightness multipliers.
\item {\bfseries{{\ttfamily Side}}} identifies the left ({\ttfamily LEFT = 1}) or right ({\ttfamily RIGHT = 2}) projector.
