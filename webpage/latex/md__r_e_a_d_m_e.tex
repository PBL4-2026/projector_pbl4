To view the html website:
\begin{DoxyEnumerate}
\item Select the "{}docs"{} branch of the project
\item Either download the ZIP or clone it.
\item Unzip the downloaded project
\item Open up the Doxygen application
\item Click on File (located up top) and select Open
\item Go to the project\textquotesingle{}s folder and open Doxyfile
\item Then, go to Run in Doxygen, press "{}\+Run doxygen"{} and then "{}\+Show HTML output"{} 
\end{DoxyEnumerate}
