Detailed Description

Provides calculations for dual-projector image projection.

Calculates overlap width, combined projection width, pixel density, image regions, and blending masks.

Creates a blending mask for one projector.

The mask maintains full brightness outside the overlap and fades brightness within the overlap. Gamma controls the shape of the fade.

Parameters

resXHorizontal resolution of one projector [px].
projectorSideSide of the projector, LEFT or RIGHT.
gammaValue controlling the shape of the fade.
Returns
Blending mask containing brightness multipliers from 0 to 1. @rtype Mask
