To view the html website:
    1. Select the "docs" branch of the project
    2. Either download the ZIP or clone it.
    3. Unzip the downloaded project
    4. Open up the Doxygen application
    5. Click on File (located up top) and select Open
    6. Go to the project's folder and open Doxyfile
    7. Then, go to Run in Doxygen, press "Run doxygen" and then "Show HTML output"
